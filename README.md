# نظام إدارة ومتابعة غيابات الطلاب

هذا التطبيق مخصص للاستعمال الإداري من طرف موظفي كلية الحقوق والعلوم السياسية بجامعة محمد بوضياف بالمسيلة، لمتابعة غيابات الطلبة وأرشفتها.

## مميزات التطبيق:
1. **واجهة تسجيل الدخول**: لحماية بيانات النظام (اسم المستخدم الافتراضي: `admin`، كلمة المرور: `admin`).
2. **لوحة القيادة الرئيسية**: توفر إحصائيات سريعة عن عدد الغيابات المسجلة.
3. **لوحة الموظفين**: تتيح إدخال بيانات غياب الطالب (اللقب، الاسم، رقم التسجيل، عام البكالوريا، المستوى، وغيرها) ويتم إنشاء رقم تسلسلي لكل إدخال آلياً. بالإضافة إلى عرض وأرشفة الغيابات المدخلة مسبقاً.
4. **تبرير الغياب**: صفحة مخصصة لإنشاء وثيقة تبرير الغياب قابلة للطباعة أو الحفظ كملف PDF بناءً على القوانين المعمول بها.

## مكونات النظام (5 ملفات):
- `index.html`: واجهة المستخدم.
- `style.css`: تنسيقات الواجهة وملف الطباعة.
- `script.js`: المنطق البرمجي لإدارة التطبيق وحفظ البيانات محلياً.
- `database.json`: ملف هيكلي يمثل قاعدة البيانات للتطبيق.
- `README.md`: دليل الاستخدام.

## طريقة التشغيل:
لا يحتاج التطبيق إلى أي خادم (Server) أو برامج إضافية.
فقط قم بفتح ملف `index.html` في أي متصفح ويب حديث (مثل Google Chrome أو Edge) وسيعمل التطبيق مباشرة.

**ملاحظة هامة:** يتم حفظ البيانات في الذاكرة المحلية للمتصفح (Local Storage) لتسهيل العمل دون الحاجة لإعداد خوادم أو قواعد بيانات معقدة، مما يجعله جاهزاً للاستخدام الفوري.
